EL PROBLEMA Y USUARIO

Usuario: Dueños o encargados de restaurantes pequeños y medianos.

El Dolor: Pierden tiempo y dinero gestionando pedidos manualmente por WhatsApp. El proceso es lento, propenso a errores (direcciones incompletas, malos cálculos) y colapsa en horas pico, generando pérdida de ventas y clientes insatisfechos.

1ER ASISTENTE PROMPT-BASED

Un agente inteligente que lee lenguaje natural desordenado y lo convierte en pedidos estructurados en JSON.

  • Extrae productos y cantidad.
  • Compara con el menú real.
  • Verifica zonas de cobertura.
  • Calcula el total con domicilios.
THERE ARE DEMOS

DEMO CORTA

INPUT (WhatsApp):
"Hola buenas! Quiero 2 hamburguesas sencillas sin cebolla y una limonada grande, para la Cra 45 #12-30, pago con Nequi"
OUTPUT (JSON Estructurado):
{
  "cliente": {"nombre": "Juan", "telefono": "..." },
  "productos": [
    {"nombre": "Hamburguesa sencilla", "cantidad": 2, "modificaciones": ["sin cebolla"]},
    {"nombre": "Limonada grande", "cantidad": 1}
  ],
  "direccion_entrega": "Cra 45 #12-30",
  "total": 49000,
  "requiere_revision": false
}

ERROR ENCONTRADO Y MEJORA

El Error (Alucinación):
Cuando el cliente enviaba un mensaje ambiguo como "me regalas la de siempre porfa", el bot inventaba un producto existente en el menú (ej. "Hamburguesa sencilla") y asumía su precio para forzar una respuesta válida.

La Mejora:
Se implementó una restricción estricta en el prompt: "No inventes productos, precios ni direcciones. Usa null y marca requiere_revision en true". Ahora el sistema detecta la ambigüedad, no inventa datos y delega la decisión a un revisor humano.
